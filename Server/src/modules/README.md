# Domain Modules

**Purpose:** Groups modular-monolith capabilities that mirror completed TSA ERP frontend workflows.

**Files:**

- `academics/` — Courses, batches, subjects and streams.
- `admissions/` — Admission and enrollment workflow.
- `assets/` — Asset inventory and events.
- `audit/` — Protected audit history.
- `auth/` — Authentication and session boundary.
- `branches/` — Branch lifecycle and isolation.
- `classes/` — Schedules and rosters.
- `dashboard/` — Permission-scoped dashboard projections.
- `demos/` — Demo inquiry lifecycle.
- `faculty/` — Teacher assignments.
- `fees/` — Challans, verified collections and receipts.
- `finance/` — Income, expenses and ledger.
- `notifications/` — Branch and role-scoped notifications.
- `organizations/` — Academy organization boundary.
- `payroll/` — Assignment-based running salary balances.
- `reports/` — Reports and exports.
- `settings/` — Academy and branch settings.
- `students/` — Student profiles and relationships.
- `users/` — Staff and branch-role assignments.

**Relationships:** Shared infrastructure and approved cross-module transactions.

**Status:** STRUCTURE ONLY — NOT IMPLEMENTED.
