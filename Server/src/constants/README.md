# Backend Constants

**Purpose:** Centralizes approved roles, permissions, statuses, error codes and cache-key contracts.

**Files:**

- `cacheKeys.js` — Will define organization, branch, role and data-version cache keys.
- `errorCodes.js` — Will define stable client-safe error codes.
- `permissions.js` — Will define canonical server permission identifiers and mappings.
- `roles.js` — Will define the five approved backend role identifiers.
- `statuses.js` — Will define approved domain lifecycle statuses.

**Relationships:** Authorization, domain modules, errors and caching.

**Status:** STRUCTURE ONLY — NOT IMPLEMENTED.
